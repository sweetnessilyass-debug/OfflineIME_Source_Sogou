## ✂️ 这把键盘经历了什么？

可以理解为一次岗位调整：打字部门正常上班，商业部门的已识别入口暂停营业。

| 项目 | 本版本的处理 |
| --- | --- |
| 中文九宫格、本地拼音、候选词 | 保留原有输入能力，未重写拼音候选算法或词库 |
| 键盘与输入设置 | 保留本地设置入口，包括模糊音、剪贴板和常用语等 |
| 联网 | 从权限清单移除 `INTERNET`；应用不申请联网权限 |
| 广告与商业推荐 | 禁用已识别的广告入口、推荐开关及相关初始化任务 |
| 皮肤商城与商业页面 | 关闭相关入口；保留可用的本地键盘界面 |
| 账号、云候选与云同步 | 关闭相关在线功能或入口 |
| 推送、在线更新与热更新 | 禁用已识别的相关组件或任务 |
| 统计与诊断上报 | 关闭已识别的采集、上传入口，同时保留输入流程需要的初始化依赖 |
| 应用首页 | 换成本地设置与试打页，启用输入法、切换键盘都在这里 |
| 语音输入 | Lite 0.2 接入内置普通话离线模型，固定为本地识别，无云端回退 |

**精简方式说清楚：**主要采用入口禁用、组件关闭和流程调整。APK 中的第三方类与资源没有全部物理删除，也没有完成对每一条代码路径的全面审计。“精简”不能自动翻译成“所有角落都检查过了”。

## 🎙️ 语音可以离线，那还需要什么？

需要麦克风，也需要你开口。暂时还没研发出读心术。

Lite 0.2 构建会内置经过校验的普通话语音资源：

- 首次启动在手机本地解压，**无需首次联网下载模型**。
- 音频交给本地解码器处理，识别模式固定为 `OFFLINE_ONLY`。
- **没有云端识别兜底**，不会在识别失败后切回在线语音。
- 使用原厂旧框架兼容资源，不声称与新版应用下载的模型相同。
- 当前按普通话使用；方言、多语言和复杂噪声场景没有可承诺的效果。
- 模型会增加安装包体积和存储占用。离线能力也得带上自己的行李。

应用不申请联网权限；语音版另外需要你手动授权麦克风。

## 🚀 安装与使用

**先看签名：**本项目构建使用独立签名，通常不能覆盖安装原版搜狗。更换签名时可能需要卸载旧应用，卸载会清除它的设置、本地学习词库及其他私有数据，请先自行确认需要保留的内容。

拿到正式发布的 APK 后：

1. 确认设备为 **ARM64**，核对版本和文件校验值后安装。
2. 打开应用，按首页提示启用输入法并切换到本版本。
3. 在试打区输入几个字，先确认基本输入和上屏正常。
4. 语音版点击“允许麦克风用于离线语音”，按系统提示授权。
5. 等待资源准备完成；可点击“检查离线语音资源”查看状态。
6. 点击试打区和键盘上的麦克风，说一句普通话，检查识别与上屏。

首次运行给模型一点解压时间。键盘正在搬行李，不一定是在装死。

## 🙋 几个容易问到的问题

**九宫格重新写过吗？**

没有重写输入算法。本项目围绕原有本地输入能力做功能精简和离线语音接入。

**为什么登录、云同步、在线皮肤不能用？**

相关在线功能已关闭，安装包也不申请联网权限。这些功能不在当前版本的支持范围内。

**离线语音会和在线识别一样准吗？**

目前没有足够测试支持这个结论。专有名词、长句和噪声环境需要继续验证，效果以实际使用为准。

**这是搜狗完整源码开源了吗？**

本仓库公开的是原创补丁脚本和辅助代码。厂商输入法、模型、词库及原有代码的权利仍属于各自权利人，详见 [第三方内容说明](NOTICE.md)。

**遇到问题怎么反馈？**

请通过仓库 Issue 提供系统版本、应用版本、具体操作和错误现象。机型信息可按自己的隐私意愿提供；分享日志或截图前，请遮住账号、聊天内容、通知、设备标识等信息。方便的话用无隐私的测试句复现。

## 🛠️ 自己构建：键盘维修间

源码与安装包分开管理。源码树和源码 ZIP 不包含原版或修改版 APK、厂商模型、词库、反编译结果、设备数据及签名私钥。

<details>
<summary>展开构建步骤与工具配置</summary>

需要 Python 3.10+、JDK 17+、Android SDK（默认 Build Tools 36.1.0 与 android-36）和 apktool 3.0.3。可通过以下环境变量配置本机工具，不在源码中填写个人目录：

- `JAVA_HOME`
- `ANDROID_SDK_ROOT`（也支持 `ANDROID_HOME`）
- `APKTOOL_JAR`（默认 `tools/apktool_3.0.3.jar`）
- 可选：`ANDROID_BUILD_TOOLS`、`ANDROID_PLATFORM`

将自行取得的原始 APK 放在 `inputs/SogouInput_20.17.0_android_sweb.apk`。仅支持 SHA-256：

```text
3eb2612040fd7daefb7e92b9de5c1a715b03f272b644e0664948742df1c7a416
```

执行：

```sh
python prepare.py
python lite/build.py
```

输出位于 `dist/`，构建记录位于各自的 `build/` 与 `logs/`，首次构建会在 `.local/signing/` 创建项目独立密钥。两个构建变体共用该本地密钥。密钥、密码和输出文件被忽略规则及发布检查排除。

### 离线语音变体

在构建语音变体前，需要本地准备匹配 `offline-voice/resource-manifest.json` 的资源压缩包：

```text
audit/offline-voice/offline_zip_64_1.zip
```

可选的 `offline-voice/fetch_resources.py` 使用原 APK 的分发配置查询已知资源任务，不包含个人账号或设备标识。运行该脚本前，需自行用 JADX 将原 APK 反编译到 `audit/jadx/`，保持其默认 `sources/` 目录结构。脚本会校验官方 MD5 和固定 SHA-256；服务若已变更则停止，不自动改用未知资源。

```sh
python offline-voice/fetch_resources.py
python offline-voice/build.py
```

`offline-voice/probe/` 是可选的模型加载探针源码，依赖同一 JADX 输出；它不录音，也不替代完整应用测试。

### 签名与本地验证

自行构建使用新密钥，与原版以及此前本地产物的签名不同。切换签名通常需要卸载原应用，并会清除其私有数据。构建脚本不会操作手机或自动卸载应用。

安装后先验证普通输入，再手动授权麦克风、测试语音。请勿上传含输入内容、账号、设备信息的截图或日志。
